# 애플리케이션과 관측 시스템을 별도 호스트로 운영한다

개발 환경의 비용과 성능은 가성비를 우선해 조정하되, 실제 운영 구조를 따르기 위해
Cosmos API와 셀프 호스팅 Langfuse를 서로 다른 GCE VM에 배치한다. 단일 VM에 함께
배치하는 비용 절감안보다 장애 범위, 배포, 리소스 확장, 데이터 수명주기를 독립적으로
관리하는 이점을 선택하며, 초기에는 각 VM의 사양을 낮게 시작해 측정 결과에 따라
수직 확장한다.

## Consequences

- API VM 장애나 배포가 Langfuse 데이터 저장소에 직접 영향을 주지 않는다.
- Langfuse의 ClickHouse·PostgreSQL·Redis·오브젝트 스토리지를 API와 독립적으로
  백업하고 업그레이드할 수 있다.
- VM과 영구 디스크 비용이 추가되지만, 서비스별 측정 결과에 따라 사양을 독립적으로
  낮추거나 높일 수 있다.
