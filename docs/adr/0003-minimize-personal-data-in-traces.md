# Trace에서 개인 프로필 데이터를 제외한다

Langfuse에는 품질 분석에 필요한 정제된 프롬프트와 모델 응답을 저장하되 사용자 ID,
나이, 성별, 임신·수유 여부, 보유 제품처럼 개인을 식별하거나 민감할 수 있는 프로필
정보는 저장하지 않는다. 실제 사용자 ID 대신 요청 단위 trace ID만 사용하며, 개발
환경의 trace는 30일간 보관한다. 사용자별 장기 분석보다 개인정보 최소화를 우선한다.

## Consequences

- 프롬프트와 응답을 이용한 생성 품질 분석은 가능하다.
- 특정 사용자의 여러 요청을 연결하는 분석은 지원하지 않는다.
- 새 trace 필드를 추가할 때 개인 프로필 데이터 포함 여부를 먼저 검토해야 한다.
